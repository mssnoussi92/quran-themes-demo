# Références

Analyses de vidéos qui ont inspiré le format. Elles servent à comprendre ce qui marche (structure, rythme, langage visuel) et ce qu'on fait autrement.

Règle du dossier : **texte seulement**. Le dépôt est public : aucune capture, aucun extrait audio ou vidéo, aucun visuel d'un tiers. Chaque plan clé est décrit par écrit, avec son timecode. On ne copie ni personnages, ni décors, ni mises en page : on s'en inspire pour concevoir les nôtres.
